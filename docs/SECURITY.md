# امنیت

## چه چیزی در سورس نیست

در این مخزن **هیچ** توکن ربات، رمز پنل، کلید API درگاه، شمارهٔ کارت، دامنه یا
آیدی عددی ادمین هاردکد نشده است. همه از این دو جا می‌آیند:

1. فایل `.env` (توکن ربات، ادمین‌ها، مسیرها، برند، یوزرنیم پشتیبانی)
2. جدول `settings` در دیتابیس (کلید پنل پاسارگارد، درگاه‌ها، شمارهٔ کارت و…)

اگر مخزن را fork کردی، `.env` خودت را بساز — و هیچ‌وقت کامیتش نکن.

## چک‌لیست پیش از انتشار/دیپلوی

- [ ] `.env` واقعی در گیت نیست (`git ls-files | grep -i env` فقط `.env.example` بدهد)
- [ ] دیتابیس و بکاپ و لاگ در گیت نیستند
- [ ] توکن ربات نو است (اگر قبلاً جایی منتشر شده، باطلش کن)
- [ ] کلید API پنل پاسارگارد فقط روی سرور خودت است
- [ ] `PANEL_ADMINS` فقط آیدی عددی خودت است
- [ ] روی سرور: `chmod 600 .env` و `chmod 600 sibil.sqlite3`

## هاردنینگ پیشنهادی سرور

```nginx
location ~ ^/(logs|backups|uploads)/ { deny all; }
location ~ \.sqlite3$             { deny all; }
location ~ /\.                    { deny all; }
location ~ ^/uploads/.*\.php$     { deny all; }
```

- سرویس ربات را با یک کاربر غیر‌root (`sibil`) اجرا کن.
- فایروال: فقط 22/80/443 باز باشد؛ پورت پنل پاسارگارد روی IP محدود شود.

## در خود کد

- همهٔ کوئری‌ها Prepared Statement هستند (`DB::one/all/exec/update`).
- تغییرهای حساس (پرداخت، موجودی، شمارش واریزی، پرداخت پورسانت) با **CAS**
  (`UPDATE … WHERE col=?`) در برابر اجرای دوباره قفل می‌شوند.
- وبهوک درگاه‌ها با امضا/هش تأیید می‌شود و مبلغ ارائه‌شده با مبلغ سفارش تطبیق
  داده می‌شود؛ «موفق» فقط بعد از confirm + verify ثبت می‌شود.
- عکس‌های احراز هویت روی دیسک ذخیره نمی‌شوند؛ فقط `file_id` تلگرام نگه داشته
  می‌شود.
- پیام‌های خطای کاربر هیچ مسیر داخلی یا جزئیات دیتابیس را لو نمی‌دهند.
